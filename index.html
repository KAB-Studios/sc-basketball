Shaded rows are home games. Region marks region games (the * on the printed schedule). Times are Eastern. Schedule as updated 10/26/26 - times can change, so check with the coach before a long drive.

iPhone

  1. Tap the red button above.
  2. Safari shows the games. Tap Add All.
  3. Pick which calendar to put them on. Done.

Android / Google Calendar

  1. Android can't open .ics files on the phone, so use a computer (or Chrome in desktop mode).
  2. Download the file from the red button, then go to calendar.google.com → gear → Settings → Import & export → Import.
  3. Pick the file and the games sync to your phone's Google Calendar app.

Outlook or other

  1. Download the .ics file.
  2. In Outlook: File → Open & Export → Import/Export → Import an iCalendar file.
